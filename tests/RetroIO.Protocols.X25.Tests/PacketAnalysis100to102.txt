PACKET ANALYSIS: Machine 100 to Machine 102 Communication Flow
================================================================

Raw Packet Sequence Analysis:
1. 0x01 0x3F 0x00 0x64    - SABM (Set Asynchronous Balanced Mode) from machine 100
2. 0x01 0x73 0x00 0x64    - UA (Unnumbered Acknowledgment) to machine 100
3. 0x09 0x01 0x00 0x64    - I-frame data packet 1
4. 0x09 0x00 0x21 0x13... - I-frame with routing data (100→102)
5. 0x09 0x22 0x21 0x13... - I-frame with response data
6. 0x09 0x29 0x00 0x64    - RR (Receive Ready) N(R)=1, P/F=1
7. 0x09 0x41 0x00 0x64    - RR (Receive Ready) N(R)=2
8. 0x09 0x64 0x21 0x13... - I-frame N(S)=3, N(R)=2
9. 0x09 0x69 0x00 0x64    - RR (Receive Ready) N(R)=3, P/F=1
10. 0x09 0x66 0x21 0x13... - I-frame N(S)=3, N(R)=1
11. 0x01 0x4B 0xB7 0xF0... - U-frame (FRMR or similar)
12. 0x09 0x81 0x00 0x64    - RR (Receive Ready) N(R)=4
13. 0x09 0xA8 0x21 0x13... - I-frame N(S)=5, N(R)=2
14. 0x09 0xA9 0x00 0x64    - RR (Receive Ready) N(R)=5, P/F=1

Detailed Packet Breakdown:

PACKET 1: SABM Connection Request
- 0x01: LAPB Address (DTE)
- 0x3F: SABM command with P=1
- 0x00 0x64: Machine ID 100 (source)

PACKET 2: UA Connection Acknowledge  
- 0x01: LAPB Address (DTE)
- 0x73: UA response with F=1 (0x63 | 0x10)
- 0x00 0x64: Machine ID 100 (destination)

PACKET 4: First Routing Data (100→102)
- 0x09: LAPB Address (DCE addressing mode)
- 0x00: I-frame, N(S)=0, N(R)=0
- 0x21 0x13: X.25 routing protocol header
- 0x00 0x19: Length = 25 bytes
- 0x00 0x66: Destination = 102
- 0x00 0x64: Source = 100
- 0xFF 0xFF: Service/Protocol ID
- 0x00 0x01: Message type/sequence
- 0xDE 0x08: Data/CRC

PACKET 5: Response with Extended Data
- 0x09 0x22: I-frame N(S)=1, N(R)=1, P/F=1
- 0x21 0x13: Same routing protocol
- 0x00 0x0E: Length = 14 bytes
- 0x00 0x66: Destination = 102
- 0x00 0x64: Source = 100
- Extended payload with additional routing info

Flow Control Analysis:
- RR frames (0x29, 0x41, 0x69, 0x81, 0xA9) provide acknowledgment
- Sequence numbers increment properly: N(R) = 1,2,3,4,5
- P/F bit alternates for flow control handshaking

Protocol Identification:
- Address 0x09 indicates DCE mode operation
- X.25 packets use routing protocol 0x21 0x13
- Machine IDs: 100 (0x64) and 102 (0x66)
- Service appears to be custom routing/messaging protocol
